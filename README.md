# Morpion 3D

A mobile video game playable on Android smartphones: a three-dimensional tic-tac-toe game.

## Overview

The base concept follows classic tic-tac-toe — align three pieces in a row — but extends it to a three-dimensional playing field made up of multiple stacked grids.

The game is played by two players on the same device, taking turns. It introduces original features not found in classic tic-tac-toe, such as special abilities that let players alter the state of the board or their opponent's pieces, along with a full game customization mode.

The goal was to offer a strategic, accessible, and original gaming experience on smartphone.

## Features

- 3D tic-tac-toe gameplay across multiple stacked grids
- Two-player local mode (same device, alternating turns)
- Special abilities to modify the board or opponent's pieces
- Customizable board sizes: 3x3x3, 4x4x4, or 5x5x5
- And more

## Tech Stack

`Unity` · `C#`

## APK Installation

The game's APK file is provided directly with this release. This method allows you to install the application without going through the Google Play Store.

**Requirements:**
- An Android device
- Allow installation from unknown sources

**Steps:**
1. Transfer the APK file to your Android device (via USB cable, email, Google Drive, etc.)
2. On your Android device, go to Settings → Security (or Settings → Apps, depending on your Android version)
3. Enable the "Unknown sources" or "Install unknown apps" option
4. Open the file manager, locate the APK file, and tap on it
5. Confirm the installation by tapping "Install"
6. Once installation is complete, tap "Open" or find the app in your app list

**Via Android Studio Emulator:**
1. Install Android Studio from developer.android.com/studio
2. Create a virtual device via AVD Manager → Create Virtual Device
3. Launch the emulator
4. Drag and drop the APK file directly onto the emulator window
5. Installation will start automatically
